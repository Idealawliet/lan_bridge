# LAN Bridge v0.11.0

- 连接握手校验软件版本。两端版本不同或对端未提供版本信息时拒绝连接，并提示切换至相同版本。
- 新增版本管理，可选择 GitHub 已发布且提供本平台安装包、SHA-256 文件的版本，升级、降级或重装。下载和安装需用户分别操作。
- 鼠标发送移除额外的 4 ms 定时等待，继续合并积压移动并保留按键顺序；Windows 鼠标注入关闭系统消息合并。实际流畅度仍需双机验证。
- README 新增实际 Flutter 界面的主界面、服务端与版本管理截图，演示设备已标注。

旧版本本身可能不具备版本校验能力；降级后请确保两端选择同一版本。

## 下载

- Windows：`lan-bridge-windows-x64-0.11.0-setup-unsigned.exe`。
- macOS：`lan-bridge-macos-0.11.0-unsigned.dmg`，支持 Apple Silicon 和 Intel。
- 提供便携 ZIP 和 SHA-256 文件，安装包为未签名预览版。
