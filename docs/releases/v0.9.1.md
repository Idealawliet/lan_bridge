# LAN Bridge v0.9.1

- 修复服务端未连接任何客户端时，屏幕布局仍显示一个不存在的“被控电脑”的问题。未启动、等待连接和停止服务后仅显示本机屏幕。
- 客户端离开或断开后立即从连接布局中隐藏，已连接数量只统计有效连接。
- 断开的设备重新被发现时，可再次拖入布局并配对。
- 未连接的客户端仅显示本机屏幕，不再显示不存在的远端键鼠主机。
