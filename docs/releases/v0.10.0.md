# LAN Bridge v0.10.0

- 新增基于 GitHub 官方 Releases API 的软件更新检查：启动时检查，也可在“设置 → 软件更新”中手动检查，无需 GitHub 账号或访问令牌。
- 按版本号比较已发布 Tag，包含预览版，自动匹配 Windows EXE 或 macOS DMG，不将旧版本误判为更新。
- 主界面提示可用更新；可查看发行说明、稍后提醒或关闭启动时检查。检查不会自动下载，也不会自动安装。
- 用户选择下载后显示进度，支持取消和重试；下载完成校验文件大小与 SHA-256，安装前再次验证文件内容。
- 安装需要再次确认：先断开控制连接并释放键鼠，再打开系统安装包并正常退出应用。Windows 按安装向导操作；macOS 在磁盘镜像中拖入 Applications 替换旧版。

## 下载

- Windows：`lan-bridge-windows-x64-0.10.0-setup-unsigned.exe`。
- macOS：`lan-bridge-macos-0.10.0-unsigned.dmg`，支持 Apple Silicon 和 Intel。
- 同时提供便携 ZIP 与 SHA-256 文件。

首次请手动安装 v0.10.0，之后即可在软件内选择后续更新。本版本为未签名预览版，系统可能显示发布者或打开确认提示。
