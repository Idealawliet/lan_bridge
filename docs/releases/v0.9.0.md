# LAN Bridge v0.9.0

- 主界面直接提供“启动服务端”和“启动客户端”，无需进入设置选择角色。连接偏好、手动 IP 和开机自启仍在设置窗口。
- 服务端与客户端双向发现；服务端可申请控制，客户端可允许或拒绝。客户端可主动申请加入服务端，由服务端同意并配对或拒绝。
- 申请列表展示处理状态，未处理申请自动重试，60 秒后过期。申请只交换设备信息，不发送 PIN，也不直接授予控制权限；连接仍需验证客户端的 6 位 PIN。
- 服务端可点击“开始控制”切入客户端，或“解除控制”断开单台设备，保留其他连接。“返回本机”保留已连接设备。
- 客户端可点击“离开服务端”立即释放输入并断开，自动生成新 PIN 重新等待，之后可申请加入其他服务端。
- 修复已离开的客户端仍留在列表时无法重新加入的问题。
