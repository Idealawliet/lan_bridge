# LAN Bridge v0.8.2

- Windows 托盘与 macOS 菜单栏显示实时连接信号格、往返延迟与延迟抖动。
- 标记当前键鼠控制本机还是远端，并区分本机正被远端控制的状态；断线后恢复本机状态。
- Windows 新增 EXE 安装器，包含应用、Flutter 数据、插件和 VC++ 运行库；支持当前用户安装与卸载。
- macOS 新增 DMG，拖动 LAN Bridge.app 到 Applications 安装。
- 保留便携 ZIP，所有下载附有 SHA-256 校验文件。

## 下载选择

- Windows 10/11 x64：`lan-bridge-windows-x64-0.8.2-setup-unsigned.exe`。
- macOS 12 或更新版本：`lan-bridge-macos-0.8.2-unsigned.dmg`，支持 Apple Silicon 和 Intel。

本版本为预览版。Windows 安装包未做 Authenticode 签名，macOS 应用未做 Developer ID 发行签名与 Apple 公证，系统可能提示未知发布者或阻止打开。请核对下载来源和 SHA-256；macOS 需按系统提示授权辅助功能、输入监控和本地网络访问。

自动化测试和安装包检查不能替代 Windows ↔ macOS 实际设备的键鼠、权限、剪贴板与拖放验收。发布构建的结果以该版本 GitHub Actions 记录为准。
