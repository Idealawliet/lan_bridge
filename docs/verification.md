- `flutter analyze`：无问题。
- `flutter test`：55 项通过（新增 2 项吸附几何测试）：10 项加密传输、11 项控制器、4 项屏幕几何、5 项界面、6 项文件传输、7 项剪贴板、4 项桌面设置、2 项多机控制组、2 项局域网发现、2 项输入路由测试。

- Windows 原生插件：使用 MinGW GCC 14、C++20 和当前 Flutter SDK 头文件，开启 `-Wall -Wextra -Werror`，v0.3 插件及四向、裁剪后的 OLE 拖放边缘通过 `-fsyntax-only` 检查（v0.1 曾编译为 PE/COFF 目标文件）。这不包含链接或运行验证。
- macOS plist/entitlements 已解析校验；局域网访问配置存在，未启用阻止全局输入的 App Sandbox。
- GitHub Actions YAML 可解析；macOS 打包脚本通过 `bash -n`。

- 新测试覆盖嵌套/空目录、零字节文件、分块、路径校验、坏摘要清理、符号链接拒绝、取消与已校验拖放回调；剪贴板覆盖双向、无回传、大小限制、暂停恢复和写入失败恢复。

- 自启配置测试验证 Windows 当前用户注册表参数、带空格路径引用、错误上报，以及 macOS LaunchAgent 路径转义和删除；这些测试未实际修改 Windows 注册表或执行登录启动。

- v0.4 多机测试使用三条真实加密 TCP 会话和模拟原生层：验证输入隔离、点击切换、边缘自动切换、释放旧客户端按键、后台移除不停止当前钩子、当前客户端断线后其他客户端继续控制、紧急断开与停止服务。
- 发现测试使用两只真实 UDP 组播套接字，验证公告发现；另覆盖 ID 去重、忙碌状态更新、地址更新、离线过期与列表上限。测试运行于同一 Linux 环境，不代表跨设备 Wi-Fi 发现已验证。
- 界面测试新增服务端发现列表、显式加入对话框和取消后不建立控制会话。v0.4 未修改 Windows / macOS 原生代码，沿用 v0.3 的编译器静态检查结果。
