# 双机验收清单

本文件是待执行的验收计划，不代表已经实测通过。每次发行应记录客户端版本、Flutter 版本、Windows/macOS 版本、CPU 架构、分辨率、显示缩放和键盘布局。修改原生输入逻辑后，需要重新执行输入与故障恢复项目。

## 构建与安装

- 在干净工作区执行 `flutter pub get`、`flutter analyze`、`flutter test`；在各系统构建 release 客户端。
- 从 ZIP 解压后启动，确认 Windows 的 DLL/data 文件完整；macOS `.app` 能启动并显示界面。
- 校验 `.sha256`，确认发行说明正确标注未签名或真实签名、公证状态。
- macOS 分别测试未授权、只授权辅助功能、同时授权辅助功能与输入监控；未授权时应显示可处理的错误而不是显示已就绪。
- 在两个系统验证中文界面、高 DPI、大字体和较小窗口，输入框、状态与断开按钮应可见。

## 连接与认证

- 在被控电脑开始监听，输入正确 IP 与密钥后连接成功；不需要云端账户或公网服务。
- 密钥错误、无效地址、端口被占用、目标离线均得到清楚错误；本机键鼠始终可用。
- 停止监听并重新开始，确认产生新密钥，旧密钥不能建立新连接。
- 已有连接时第三台电脑不能抢占控制；无效握手不能导致界面卡死。
- 使用网络抓包确认输入帧不包含明文按键或明文鼠标事件；配对密钥不能出现在网络帧或日志中。
- 错误密钥连接后，正确配对仍可成功；反复连接、断开至少 20 次，无监听端口泄漏。

## 跨屏与输入

- 左右两种排列分别反复穿越边缘，进入目标后的垂直位置与出发点比例一致；跨回时不立刻反弹。
- 在屏幕顶部/底部、不同分辨率和 Windows 125%/150% 缩放下测试；指针不能越界或产生明显跳跃。
- 在目标屏幕的远端边缘持续移动，光标应保持在目标内；仅相接边缘可返回主机。
- 在主机本地操作时按键只进入主机；跨屏后按键进入目标且主机不收到副本。
- 字母、数字、功能键、方向键、回车、退格、Delete、Home/End、PageUp/PageDown、数字键盘逐项测试。
- 分别测试左右 Shift/Ctrl/Alt/GUI 修饰键、长按重复、组合快捷键；按键释放后不能出现“卡键”。
- 左右/中键、双击、侧键、拖拽选中文本、垂直与水平滚轮逐项测试；目标接收到的事件不能再被回传。
- Windows 与 macOS 的物理键位、输入法和快捷键差异须记录；媒体专用键等不支持项目不得标注已支持。
- 从主机进入被控屏幕前，按住键或鼠标按钮应阻止跨屏；松开后再次移向边缘应能切换。普通反向返回需松开鼠标，并释放被控端的模拟输入；文件拖放走专用流程。任何情况下都能用紧急快捷键恢复本地输入。

## 故障恢复

- 指针在目标时，在键鼠主机按 Ctrl+Alt+Esc / Control+Option+Esc，本地输入立即恢复。
- 在被控电脑按紧急快捷键，确认远程输入停止且模拟按键/鼠标按钮被释放。
- 在按住 Shift 或鼠标按钮时断网、关掉对端、强制结束源应用，确认故障检测后两端输入恢复且没有卡键。
- 模拟 Flutter 端心跳停止，原生保护应在约 2.5 秒超时后解除输入抑制并释放模拟输入。线程调度和系统负载可能增加延迟，应记录实测值。
- 锁屏/解锁、睡眠/唤醒、Wi-Fi 切换后连接能安全结束并重新建立；不应在重连后重放旧输入。
- 退出应用、关闭窗口、停止监听后端口与原生钩子/tap 应释放，本机鼠标无残留约束。
- 分辨率、主屏幕和缩放改变后重新连接；多显示器、UAC/安全桌面、系统安全输入等边界应有清楚记录。

## v0.2 剪贴板与系统文件拖放（待实机验证）

- Windows → macOS、macOS → Windows 及同系统双机分别测试文本、中文、多行与图片剪贴板；确认无回传循环，连接前和暂停期间的复制不补传。
- 从 Explorer / Finder 选中多个文件及含嵌套、空目录的文件夹，按住左键跨边缘，等待就绪后拖入对端指定目录。核对内容、目录结构、源文件保留及实际落点。
- 从被控屏幕反向拖回主机，覆盖左右排列、Retina / DPI 缩放。检查接收的系统拖放可以连续移动并正常松开。
- 在准备前、传输中、原生拖放中分别提前松开、按紧急快捷键、断网和退出应用；不能残留按键、鼠标锁定或未完成临时目录。
- 模拟磁盘满、剪贴板占用、拒绝普通传输、取消、同名文件、非法路径、符号链接和校验失败；连接及本机输入应按设计恢复。
- 检查接收副本保留，目标窗口异步复制完成后再手动清理缓存。运行中改变屏幕配置后重新连接。
- 大文件跨屏准备可能超过 10 分钟，应取消并改用应用内传输；记录实际吞吐与超时体验。


## v0.3 布局、网络角色、自启（待实机验证）

- 分别将主机作为客户端和服务端建立连接，核对只有主机键鼠控制对端；两端选择相同键鼠角色时应拒绝连接。连接中禁止变更角色和布局。
- 用鼠标拖动预览到四个方向，调整正负错位、居中与 90% 极值；非相接边缘不穿越，相接区域来回衔接正确。测试不同 DPI / Retina。
- 在全部四向布局及错位下，分别从 Explorer / Finder 拖到对端再拖回本机，确认拖放边缘只占相接区域；macOS 上边缘菜单栏与下边缘 Dock 需特别检查。
- 退出重开后检查键鼠角色、网络角色、排列和错位恢复；配对密钥不得恢复，应用不得自行监听或连接。
- 在固定安装位置启用自启，退出并注销 / 重新登录，确认只启动一个应用实例；关闭后再登录不启动。Windows 检查当前用户 Run 项，macOS 检查 LaunchAgent。实际系统行为尚未自动化验证。
- 应用路径含空格、中文、& 字符时自启应正常；无权限或配置写入失败时界面显示失败且不得假报成功。移动应用后重新设置自启，卸载前关闭。


## v0.4 多客户端发现与控制组（待实机验证）

- 至少一台服务端和三台 Windows / macOS 客户端，使用同一有线局域网及 Wi-Fi 分别测试。客户端先开启可发现模式，服务端应显示名称、平台、地址；没有运行应用的电脑不应作为客户端出现。
- 逐台加入，错误密钥应失败且不影响已加入会话；已被其他服务端控制的客户端显示忙碌，不能抢占。
- 在右、左、上三条边缘反复进入，点击选择切换；旧客户端必须释放按键，未选中客户端不得收到键鼠或剪贴板。测试相接区域重叠时的优先级。
- 对焦点客户端断网或退出，再选择另一台仍在线客户端；移除后台客户端不能停止当前键鼠。测试紧急快捷键和停止多机服务，所有模拟按键都应释放。
- 对当前选中客户端验证双向剪贴板、文件 / 文件夹传输和系统跨屏拖放；传输时切换应被拒绝。后台客户端的普通文件接收请求应切换到该客户端后处理。
- 切换 Wi-Fi、禁用一个网卡、同时存在有线 / Wi-Fi / VPN 时核对发现地址；关闭客户端，未连接发现项应在约 7 秒后过期。已加入项保留离线状态直到移除。
- 验证 Windows 私有网络防火墙的 UDP 24873 与客户端 TCP 24872，macOS 本地网络权限、AP 客户端隔离及组播限制。记录实际网络的可发现性，不将单机组播测试当作 Wi-Fi 实测。
- 关闭服务、退出应用和重启后不能残留捕获或自动信任旧密钥。移除客户端后重新开启可发现模式，应生成新配对密钥。


## v0.5 拖拽排列和控制申请

- 可用设备卡片拖入被控区域，应打开密钥验证；取消或错误密钥不能加入控制组，忙碌设备不可拖入。
- 同时显示多个已加入屏幕；拖动时连续跟随鼠标，靠近四边及角点显示吸附预览，松开后远端收到新布局。远离边缘松开恢复原位置。
- 在正在远程控制时调整布局，旧会话应先返回本机并释放按键；文件传输期间调整应拒绝，不能中途改变文件拖放会话。
- 不同窗口宽度及 Windows DPI / macOS Retina 下验证拖入位置、角点吸附与鼠标穿越。新旧协议版本互连应拒绝。


## v0.6 后台生命周期（待原生实机验证）

- 服务端连接至少两台客户端，关闭主窗口，等待至少 30 秒，键鼠跨屏、剪贴板、UDP 发现和文件传输应继续运行；分别覆盖 Windows × / Alt+F4、macOS 红色关闭按钮 / Command+W。
- Windows 单击托盘图标，macOS 菜单栏“打开”或 Dock 再次打开，应恢复同一窗口和会话，不创建新服务。重复隐藏 / 打开。
- Windows Explorer 重启后验证托盘恢复；托盘不可用时关闭窗口应最小化而非失去入口。任务栏 / 托盘无残留图标。
- 托盘或菜单栏“退出”、macOS Command+Q，确认退出前释放所有模拟输入、断开所有客户端并移除未完成临时文件；重复退出请求只清理一次。
- 退出清理报错时应用保留并可再次尝试退出。休眠唤醒、注销、系统关机按照操作系统实际行为验收，不将后台运行等同于系统服务。


## v0.7 切换流畅度与混合分辨率（待原生实测）

- 4K → 1080p、1080p → 4K、Retina → Windows、竖屏 → 横屏，在四条相接边的 0%、25%、50%、75%、100% 位置来回穿越；核对相对位置。至少测试 100%、150%、200% 缩放。
- 在不同错位排列中斜向快速穿过接缝，核对穿越交点不因一次大幅鼠标移动而上下跳变。
- 125 / 500 / 1000 Hz（及设备支持的更高回报率）实体鼠标连续移动、滚轮、单击、按住拖动；检查手感、移动距离、按键顺序，无卡键或意外断开。
- 三台客户端连续切换至少 60 次；按住字母 / 修饰键切换，应释放旧端模拟按键，新端等待实体按键松开。立即从本机另一条边缘进入新电脑，不应有全局固定等待。
- 输入时复制大文本 / 图片或让剪贴板被其他应用占用，键盘松开和返回本机不应被剪贴板写入阻塞。
- 在跨屏接管中切换、更新布局、断开旧客户端或触发紧急恢复，检查旧端不重新激活，也不会在新端收到旧按键。
