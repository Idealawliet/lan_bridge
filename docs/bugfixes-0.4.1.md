# v0.4.1 缺陷修复记录

检查日期：2026-10-25。范围：Dart 多机输入路由、会话清理、剪贴板异步状态。

| 问题 | 复现 / 影响 | 修复 |
| --- | --- | --- |
| 旧按键投递到新客户端 | 阻塞输入队列后切换焦点，旧键被投递到新焦点；新增测试在修复前失败 | 入队保存焦点版本，焦点变化丢弃旧按键；边缘移动仍可触发自动切换 |
| 紧急恢复后处理队列残留 | 阻塞输入队列后触发 emergency，随后仍出现 key；新增测试在修复前失败 | 捕获代次使紧急恢复、停止、错误之前的事件失效；暂停期间不接纳新事件 |
| 剪贴板失败后无法重试相同内容 | 接收端写入失败，重新复制同一内容仍不发送；新增测试在修复前失败 | 仅收到成功确认后记录发送摘要 |
| 暂停恢复发送旧剪贴板 | 读取被挂起时暂停并重新开启，旧读取仍被发送；新增测试在修复前失败 | 同步代次校验异步读取及各发送块，取消旧任务；初始化基线也校验代次 |
| 焦点切换与未完成的系统写入竞争 | 已发起的 OS 剪贴板写入无法撤销，可能在新的焦点基线建立后才完成 | 切换先暂停旧剪贴板并等待已开始的写入完成；断开会话也等待写入收尾，输入恢复仍优先执行 |
| 已移除客户端保留输入通道 | 失败加入、移除和停止服务只移除控制器，没有移除路由通道 | 关闭并移除通道；回归测试断言失败加入和停止服务后通道表为空 |

同时将最后一个输入会话停止时的订阅清理移入 finally，确保原生停止报告错误时仍取消订阅。剪贴板暂停期间作废的会话若收到延迟分块，返回拒绝，不因此中断键鼠连接。

验证：53 项完整自动化测试通过；静态分析无问题。键鼠路由使用模拟原生层，多机通信使用真实加密 TCP；本次没有执行 Windows / macOS 原生运行或跨设备 Wi-Fi 验收，不能据此保证不存在其他平台问题。
